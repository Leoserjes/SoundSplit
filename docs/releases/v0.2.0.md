# harmonIA v0.2.0

Release date: 2026-05-31
Status: Approved

## Included

- First working Desktop -> API analysis job flow.
- Explicit development CORS origins for the desktop shell.
- Typed frontend job API client.
- Loading, success, and error UI states.
- Dynamic job summary and artifact rendering.
- Shared contract alignment for `source_name`.
- Expanded backend and frontend regression coverage.

## Validation

- `npm audit`: passed with 0 vulnerabilities.

- `npm run desktop:test`: passed with 10 tests.
- `.venv\Scripts\python.exe -m pytest --rootdir=. apps\api\tests workers\ai\tests`: passed with 10 tests.
- `.venv\Scripts\python.exe -m compileall apps\api workers\ai`: passed.

## Known Limitations

- Jobs are still stored in memory.
- Source name is mocked as `demo.wav`.
- Real upload, queueing, persistence, and AI processing remain out of scope.
- Pytest cache emits a non-blocking OneDrive filesystem warning.

## Deferred Distribution Work

Clean-machine installation validation, CI Windows builds, API environment configuration, WebView2 strategy, and code-signing planning are deferred to Sprint 3. Offline mode is not planned in the near term.

## Rollback Suggestion Criteria

Suggest rollback to the previous stable release if:

- The desktop app cannot create jobs through `POST /v1/jobs`.
- The UI does not show returned job state or artifacts.
- A regression causes build or test failures after release.

Rollback must be suggested and approved before execution.
