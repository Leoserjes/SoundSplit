# harmonIA v0.3.0

Release date: 2026-06-18
Status: Approved

## Included

- First local audio upload ingestion loop.
- Desktop file picker for `.wav`, `.mp3`, and `.flac` files.
- Desktop drag-and-drop selection for local audio files.
- Selected filename display before analysis starts.
- Multipart desktop API client for `POST /v1/jobs/upload`.
- FastAPI multipart upload endpoint with in-memory queued job creation.
- Backend validation for unsupported extensions, empty files, and files larger than 100 MB.
- Existing mocked artifacts returned for uploaded local files.
- Upload contract documented in `packages/contracts/upload.schema.json`.
- Expanded backend, frontend, and CORS regression coverage.
- Vite audit fix applied, clearing the high-severity advisory reported by `npm audit`.

## Validation

## Known Limitations

- Uploaded bytes are validated and discarded after request handling.
- Jobs are still stored in memory.
- Returned analysis artifacts remain mocked.
- Storage, Redis queueing, PostgreSQL persistence, audio decoding, normalization, and real AI processing remain out of scope.
- Native Tauri file-picker and drag-and-drop behavior still need manual validation outside the current browser automation surface.
- Distribution hardening remains deferred to Sprint 3.
- Source release/tag is approved; native installer artifacts are not part of this release checkpoint.

## Release Notes For Users

harmonIA now supports selecting or dropping a local audio file and starting an analysis job from that file. The backend validates the filename extension and file size, then returns the same mocked analysis artifacts while the real processing pipeline remains deferred.

## Rollback Suggestion Criteria

Suggest rollback to `v0.2.0` if:

- The desktop app cannot load the analysis workspace.
- Valid `.wav`, `.mp3`, or `.flac` files cannot create queued upload jobs.
- Invalid upload inputs are accepted silently or crash the app.
- The upload flow regresses the existing job/artifact display.
- Build, test, or audit gates fail after release.

Rollback must be suggested and approved before execution.
